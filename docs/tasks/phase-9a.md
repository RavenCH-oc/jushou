# Phase 9a：視覺整理（一）共用元件與頂部列

先讀 `CLAUDE.md`、`status.md`。Phase 8 已合併並部署。

## 為什麼做

老師試用後覺得操作邏輯清楚，但每個畫面看起來像「測試用的半成品」：純白背景、所有東西都是一樣粗的 2px 灰框、沒有頂部列，每頁左上角一顆「← 回首頁」大框框。

Phase 9 分四個 PR，**這是第一個**：

1. **9a（這個）**：顏色規則、按鈕、卡片、輸入框、對話框、表格、分頁籤這些共用元件，加上老師端頂部列＋麵包屑
2. 9b：老師端各頁面的版面（首頁、班級、名冊、分組、題組、題目編輯、上課紀錄）
3. 9c：上課相關功能（上課／投影、小工具、搶答、互評）
4. 9d：學生端

風格已經和使用者確認：**簡單現代，灰藍色背景＋白色卡片＋深色頂部列**，不做 logo。

**只改外觀，不改功能**：不動 API、資料、路由、按鈕文字和操作流程（頂部列取代「← 回…」連結是唯一的例外，見第 3 節）。

## 1. 顏色與基本規則（`src/shared/base.css`）

把 `:root` 換成下面這組變數（名稱可以微調，但值要照這個）。之後所有 CSS **只用變數，不再寫死色碼**。

```css
/* 底色與表面 */
--bg-page: #d5dce6;        /* 頁面背景（灰藍） */
--surface: #fff;           /* 卡片、輸入框、次要按鈕、對話框 */
--surface-soft: #f3f5f8;   /* 卡片裡的淺色區塊：表格標題列、作答內容框、長條圖底 */

/* 文字 */
--text: #1a1d23;
--text-muted: #525a68;     /* 在灰藍底和白底上都要夠清楚 */

/* 框線 */
--border: #c9d1dc;         /* 卡片、分隔線，一律 1px */
--border-strong: #8592a5;  /* 輸入框、次要按鈕、選項框，1px（白底上對比要 ≥ 3:1） */

/* 主色 */
--primary: #1f4aa8;
--primary-hover: #193d8c;
--primary-soft: #e6edfa;   /* 選取中的選項、目前所在的項目 */
--primary-text: #fff;

/* 頂部列 */
--appbar: #1f2b3e;
--appbar-text: #fff;
--appbar-muted: #b8c3d4;

/* 狀態：文字色＋柔和底色成對使用 */
--success: #1b6b3a;  --success-soft: #e1f2e7;
--warning: #8a5a00;  --warning-soft: #fdf1d8;
--danger:  #b3261e;  --danger-soft:  #fbe9e7;

/* 陰影與圓角 */
--shadow: 0 1px 3px rgba(20, 30, 50, 0.10);
--shadow-lg: 0 8px 24px rgba(20, 30, 50, 0.18);
--radius: 10px;
--radius-sm: 6px;
```

字級、間距、`--tap` 保持不變（投影和手機的大小規則不能動）。

**舊變數怎麼處理**：`--bg` 和 `--bg-soft` 在各個 CSS 裡被當成「白色表面」或「淺灰區塊」用。請逐一看用途換成新的：`body` 背景 → `--bg-page`；按鈕、輸入框、卡片、選項底色 → `--surface`；淺灰區塊 → `--surface-soft`。換完刪掉舊變數，不要留別名。

**寫死的色碼**：`teacher.css`、`student.css`、`question-view.css` 裡大約有 50 個寫死的色碼（`#fff5f4`、`#eef2fb`、`#1b6e2b`、`#8a9099` 之類）。有明顯對應的就換成上面的變數（例如淡紅底 → `--danger-soft`、選取的淡藍底 → `--primary-soft`、綠字 → `--success`）。找不到對應、而且是某個功能專用的顏色（例如長條圖、搶答名次），**先留著**，在 PR 列出來，9b～9d 再處理。

## 2. 共用元件

### 按鈕分三級

| 等級 | class | 長相 | 什麼時候用 |
| --- | --- | --- | --- |
| 主要 | `.btn` | 主色填滿、白字、粗體 | 每個畫面一個（「開始上課」「新增第 5 題」「停止作答」） |
| 次要 | `.btn .btn-secondary` | 白底、1px `--border-strong` 框、**深色字（`--text`）**、一般粗細 | 其他看得到的動作（「預覽全部」「登出」） |
| 文字 | `.btn-text`（新增） | 沒有底色和框、主色字、**不加底線** | 一排裡比較不重要的動作（9b 會把題目卡的「複製」「上移」「刪除」改用這個） |

- `.btn-text`：最小高度 44px、左右 padding 12px、`--radius-sm`，滑鼠移上去時淡淡的 `--primary-soft` 底色。這一輪**只建立樣式**，除了下面 `.link-button` 那 3 處以外，先不要把現有按鈕改成文字按鈕（那是 9b 的事）
- `.link-button`（3 處）：改用 `.btn-text`，刪掉 `.link-button`
- `.btn-danger`：`--danger` 填滿、白字，保留
- **停用狀態**：現在是 `opacity: 0.6`，主要按鈕看起來像壞掉的淡藍色。改成明確的灰：底色 `#c3cad5`、字 `#4a5260`、框同底色、`cursor: default`。三種按鈕的停用都要看得懂（文字按鈕停用就是灰字）。這兩個灰色可以做成變數
- 滑鼠移上去：主要按鈕變 `--primary-hover`，次要按鈕底色變 `--surface-soft`。不要 transition 動畫
- 焦點外框：維持 3px 主色 outline、offset 2px
- `.btn-small`、`.btn-block` 尺寸不變

### 卡片、輸入框、選項

- `.card`：`--surface` 白底、1px `--border`、`--radius`、`--shadow`。拿掉現在的灰底
- `.card-danger`：`--danger-soft` 底、1px `--danger` 框
- `.field`（含 textarea、select）：白底、1px `--border-strong`，聚焦時主色 outline。高度不變
- `.choice`（老師端的單選／多選列）：白底、1px `--border-strong`。選取時框線變主色、底色 `--primary-soft`；**選取前後版面不能跳動**（框線粗細改變的話用 `box-shadow: inset` 補，不要真的改 border 寬度）
- 學生端的作答選項（`question-view.css`）這一輪只換變數，不改長相，9d 再整理

### 對話框

- `.overlay`：背景 `rgba(15, 22, 35, 0.55)`
- `.modal`：白底、`--radius`、`--shadow-lg`、沒有框線
- 搶答、計時器「時間到」等全畫面提示只換變數，版面 9c 再處理

### 分頁籤、表格

- `.tabs`：底線改 1px `--border`；目前分頁的底線 3px 主色、字主色。其他分頁字用 `--text-muted`
- `.table-wrap`：做成白色卡片（`--surface`、1px `--border`、`--radius`、`overflow` 照舊）。表格放在灰藍底上才不會像浮在空中
- `.table th`：`--surface-soft` 底；分隔線 1px `--border`
- 錯誤列、缺席列換成狀態變數（`--danger-soft`／`--surface-soft` ＋ `--text-muted`）

### 其他

- `.error` → `--danger`、`.ok` → `--success`、`.muted` → `--text-muted`
- `.offline-note`：`--warning-soft` 底、1px `--warning` 框、`--warning` 字
- 登入頁：表單放進一張置中的 `.card`，標題「舉手・老師登入」

## 3. 老師端頂部列＋麵包屑

### 元件

在 `src/teacher/ui.tsx` 加一個 `AppBar`：

```tsx
<AppBar crumbs={[{ label: "首頁", href: href("/") }, { label: cls.name }]}>
  {/* 可選：右側的東西，例如首頁的「登出」 */}
</AppBar>
```

- 整個寬度的深色列（`--appbar`），放在 `<main class="page">` **外面**、頁面最上方，不要 sticky（舊電腦捲動效能差，也不需要）
- 左邊固定寫「**舉手**」（白色粗體，**不是**連結，避免跟「首頁」重複），後面接麵包屑，用「›」分隔
- 麵包屑前面每一層是連結（`--appbar-muted` 色，滑鼠移上去變白、加底線），**最後一層是目前頁面**，白色、不是連結、加 `aria-current="page"`
- 高度約 56px；文字 18px；每個連結的可點範圍至少 44px 高
- 名稱很長時（班級名、題組名），中間的層級用 `text-overflow: ellipsis` 截斷（例如最多 16em），**1366px 寬時整列不能換行**
- 螢幕寬度 700px 以下：只顯示「舉手」和上一層的連結，寫成「‹ 上一層名稱」
- 右側 slot 的按鈕用頂部列專用樣式（白字、透明底、1px `--appbar-muted` 框），不要直接放白底的 `.btn-secondary`
- `.topbar` 這個 class 名稱已經被頁面標題列用掉了，新元件請用 `.appbar`

### 每一頁的麵包屑

用頁面本來就有的資料，**不要為了麵包屑新增 API 或欄位**。資料裡沒有的層級就省略。

| 頁面 | 麵包屑 |
| --- | --- |
| 首頁 | （沒有麵包屑）右側放「登出」 |
| 新增班級 | 首頁 › 新增班級 |
| 新增題組 | 首頁 › 新增題組 |
| 班級頁（各分頁） | 首頁 › {班級名} |
| 新增分組 | 首頁 › {班級名} › 新增分組 |
| 分組頁 | 首頁 › {班級名} › {分組名}；班級連到該班的「分組」分頁 |
| 題組頁 | 首頁 › {題組名} |
| 題組預覽 | 首頁 › {題組名} › 預覽 |
| 題目編輯 | 首頁 › {題組名} › 修改第 N 題（新增時「新增第 N 題」） |
| 開始上課 | 首頁 › 開始上課 |
| 上課紀錄 | 首頁 › {班級名} › {上課日期時間}；班級連到該班的「上課紀錄」分頁 |
| 題目詳情 | 首頁 › {班級名} › {上課日期時間} › 第 N 題 |
| 學生歷次表現 | 首頁 › {班級名} › {座號} {姓名}；班級連到該班的名冊 |

- 加了頂部列的頁面，**刪掉**原本的「← 回…」連結（共 12 處，見 `grep -rn 'class="back"' src/teacher`）
- 首頁：大標題「舉手」拿掉（名稱已經在頂部列），「登出」移到頂部列右側，「開始上課」留在原位
- `Loading` 元件也顯示頂部列（沒有麵包屑），避免載入完成時畫面跳一下
- 每頁的 `<h1>` 保留

### 不加頂部列的畫面

- **上課中的畫面**（`lesson.tsx` 的 `LessonPage`）和**分組投影**（`/grouping/:id/show`）：維持原樣，它們是投影用的全畫面。上課畫面左上的「← 回首頁（課會繼續進行）」也保留，9c 再處理
- `.back` 樣式因此還會被用到一處：換成新變數（1px 框、白底）就好
- 登入頁、連不上伺服器頁：不加頂部列

## 4. 學生端與上課畫面：只要不壞

`base.css` 是共用的，學生端和上課畫面會跟著換顏色。這一輪**不整理它們的版面**，但要確認：

- 學生端各狀態（選座號、等待、作答、已送出、公布結果、互評、搶答、下課結果）沒有看不清楚或破版的地方。頁面背景會變成灰藍色，直接放在背景上的文字要夠清楚
- 上課畫面在 1366×768 和 1920×1080 沒有破版，題目、選項、作答人數在投影上仍然是深字淺底、對比清楚
- 有問題只做**最小修正**讓它能看，在 PR 註明，留給 9c／9d
