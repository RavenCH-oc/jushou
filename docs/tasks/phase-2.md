# Phase 2：題組與題目編輯

先讀 `CLAUDE.md`、`docs/PRODUCT.md`、`status.md`。Phase 1 已合併到 main。

## 目標

老師可以建立題組、在題組裡新增五種題型的題目、看到「學生會看到的樣子」。這個階段還不能上課出題（Phase 3 才做），學生端不變。

## 資料

- 題組：名稱、建立時間、最後修改時間。題組**不屬於任何班級**，可以在不同班使用
- 題目：所屬題組、順序、題型、題目文字、說明（選填）、配分、答案設定
- 題型與答案設定的 TypeScript 型別放 `src/shared/questions.ts`，答案設定在 D1 存成一個 JSON 欄位即可
- Phase 3 上課時會把題目內容**複製一份**存進上課紀錄，所以之後修改或刪除題目不會影響舊紀錄。這個階段不需要做版本或鎖定

## 題型與編輯方式

| 題型 | 老師怎麼設定 | 驗證 |
| --- | --- | --- |
| 是非題 | 選「○ 對」或「✕ 錯」為正確答案 | 必須選一個 |
| 單選題 | 選項列表，點選項旁的「設為正確答案」 | 2～8 個選項，剛好 1 個正確 |
| 多選題 | 同上，可勾多個正確答案 | 2～8 個選項，至少 1 個正確 |
| 填空題 | 見下方 | 至少 1 格，每格至少 1 個答案 |
| 簡答／申論 | 只有題目文字 | 無 |

**填空題**：老師在題目文字裡按「插入空格」按鈕，游標位置插入 `＿＿＿`（連續 3 個以上的全形底線算一格）。下方自動依序列出「第 1 格、第 2 格…」，每格一個輸入框，可以填多個可接受答案，用頓號「、」或換行分開。手打 `＿＿＿` 也要能辨識。英文不分大小寫的設定先固定為「不分」，不用做開關。

**選項**：可新增、刪除、上下移動。選項上的字母（A、B、C…）依順序自動產生，不用讓老師輸入。

配分：正整數，預設 1，上限 100。

## 評分與學生可見資料（重點測試）

在 `src/shared/grading.ts` 寫：
- `gradeAnswer(question, answer)`：依 `docs/PRODUCT.md` 的規則評分。填空題回傳每一格對錯；簡答回傳「待批改」
- `toStudentView(question)`：去掉所有正確答案、可接受答案之後的題目資料。Phase 3 送給學生的只能是這個

這兩個函式這次就要寫好並有完整測試（各題型對／錯／未作答、填空的全形半形與前後空白與大小寫、多選少選和多選、`toStudentView` 結果裡找不到任何答案）。

## 老師端畫面

### 首頁
在「班級」下面加「題組」區塊：題組列表（名稱、題數、最後修改時間）＋「新增題組」按鈕。

### 題組頁
- 題目列表：題號、題型、題目文字前 40 字、配分
- 每題可：修改、複製、上移、下移、刪除（要確認）
- 主要按鈕：「新增題目」→ 先選題型（五個大按鈕，各附一行說明）→ 進入編輯
- 次要：改題組名稱、複製整個題組、刪除題組（確認，寫清楚會刪掉幾題）
- 「預覽全部」：依序顯示每一題學生看到的樣子

### 題目編輯頁
- 上方：題型（建立後不能改；要換題型就刪掉重建，畫面上要寫）
- 題目文字（多行）、說明（選填，收合在「加上說明」連結後面）、配分
- 依題型的答案設定（見上表）
- 右側（手機時在下方）即時顯示「學生看到的樣子」
- 「儲存」為主要按鈕；有沒儲存的修改時離開，要問「還沒儲存，確定要離開嗎？」
- 驗證錯誤顯示在出錯的欄位旁邊，不要只在最上方

### 學生題目元件
「學生看到的樣子」的元件放 `src/student/question-view.tsx`，老師端預覽直接 import。Phase 3 學生作答時會用同一個元件，所以要照學生端的規格做：手機直式、選項整列可點、按鈕至少 48px。這次只需要顯示和可點選的外觀，不用送出。

## Phase 1 審核後的小修正（一起做）

1. 「新增一位學生」的座號欄：目前清空後會自動跳回預設座號，沒辦法清掉重打。改成預設座號放在 placeholder，欄位留空時送出才用預設值
2. 分組編輯頁：可以「新增一組」；點組名的對話框裡加「刪除這一組」（組員回到未分組，要確認）。手動分組時組數打錯就不用整套刪掉重建
