# Phase 9b：視覺整理（二）老師端各頁面

先讀 `CLAUDE.md`（特別是「樣式規則」）、`status.md`、`docs/tasks/phase-9a.md`。9a 已合併並部署，使用者看過覺得不錯。

## 為什麼做

9a 換好了顏色、共用元件和頂部列，但各頁面的**排列**還是原本的樣子：題目卡一整排五顆框框按鈕、名冊和成績表的姓名是底線藍色連結、首頁是一長條、分組要「點組名」才能改名（看不出來）。這一輪把老師端一般頁面整理乾淨。

**只改外觀和排列，不改功能**：API、資料、路由、每個按鈕做的事都不變。按鈕可以換位置、換等級（主要／次要／文字），文字盡量不改；要改字的地方下面會寫。

這一輪的範圍：首頁、新增班級、新增題組、班級頁（四個分頁）、新增分組、分組頁、題組頁、題組預覽、題目編輯、上課紀錄（三個分頁＋題目詳情＋簡答批改）、學生歷次表現。

**不在這一輪**：開始上課頁、上課畫面、分組投影、小工具、搶答、互評（9c）；學生端（9d）。

## 1. 先補兩個共用元件

### 危險的文字按鈕

`base.css` 加 `.btn-text-danger`：跟 `.btn-text` 一樣，但字是 `--danger`、滑鼠移上去底色 `--danger-soft`。用在「刪除」這類文字按鈕。點了還是照舊跳確認對話框。

### 「？」說明（`Help` 元件，放 `src/teacher/ui.tsx`）

- 一顆小的「？」按鈕（44×44px 圓形、1px `--border-strong` 框、`--text-muted` 字），放在標題或標籤旁邊
- **點一下**在下方展開一段說明（`--surface-soft` 底、`--radius-sm`、內文字級），再點一下收起。不要 hover、不要浮動的 tooltip、不要動畫
- `aria-expanded`、`aria-controls`、`aria-label`（例如「計分方式說明」）
- 這一輪只用在下面三個地方。**不要**把頁面上現在已經顯示的說明文字收進「？」裡（老師靠那些文字在用）
  1. 班級頁的加入碼旁：「學生上課時在手機輸入這組數字加入。上課中不能更換，要換到『班級設定』。」
  2. 上課紀錄「學生成績」分頁的標題旁，說明計分方式（照 `src/shared/records.ts` 的規則寫成白話）：沒加入也沒交答案算缺席，分數留空；有出席沒作答算 0 分；沒出過的題目不算；簡答還沒批改先算 0 分；不計分的題目不列入總分
  3. 「依分組看」分頁的標題旁：「用的是這堂課結束時的分組。之後再換組，這裡不會變。」（早期沒有快照的課，照現在的註明文字）

## 2. 共用的排列規則（這一輪每頁都照這個）

- **列表用「一張卡片＋分隔線」**，不要一列一張卡片。卡片標題列放 `h2` 和這一區的按鈕；每一列 1px `--border` 分隔，最後一列沒有線
- **可以點進去的列**：整列都能點（滑鼠移上去底色 `--surface-soft`、`cursor: pointer`），列尾放一個 `--text-muted` 的「›」。用 `<a>` 包整列內容，鍵盤 Tab 要停得到
- **表格裡的連結**（姓名、日期）：字用 `--text`、不加底線，滑鼠移上去才加底線。整列沒有其他按鈕或勾選框時，整列都可以點（點勾選框或按鈕不能觸發跳頁）
- **一個畫面一個主要按鈕**。班級頁標題列已經有「開始上課」，所以分頁裡的「貼上名冊」「新增分組」「匯出多堂課」改成次要按鈕
- **次要動作用文字按鈕**：一排裡不常用的（複製、上移、下移、刪除、重新隨機…）改 `.btn-text`；刪除用 `.btn-text-danger`
- **空狀態**：在卡片裡寫一句白話說明，旁邊或下面放該區的新增按鈕。保留現在的文字（「還沒有班級。按『新增班級』開始。」之類）
- 剩下的 2px 框（分組名牌、題目編輯選項框、題目詳情的「誰選了什麼」區塊）改 1px
- 這一輪的頁面不再寫死色碼。9a 留下的 `.bar-fill`（`#6b7a99`）、`.row-absent`（`#8a9099`）在這一輪處理：長條圖一般顏色在 `base.css` 加一個變數（例如 `--chart: #6b7a99`），缺席列用 `--text-muted`

## 3. 各頁面

### 首頁

- **最上面一張卡片**：
  - 沒有上課中：左邊「開始上課」標題＋一行說明「選班級和題組，學生用手機加入」，右邊主要按鈕「開始上課」
  - 有上課中：整張變成 `--warning-soft` 底，「上課中：{班級}」＋主要按鈕「回到課堂」，旁邊次要按鈕「開始上課」（功能不變，只是不再孤零零放右上角）
- **下面兩欄**（寬度 ≥ 1100px；以下變一欄）：
  - 左欄：「班級」卡片（列表：班級名粗體、右邊「N 位學生」、列尾 ›），下面「最近上課」卡片（照現在的內容：班級・題組、時間、出席、未批改提醒）
  - 右欄：「題組」卡片（題組名粗體、右邊「N 題・修改時間」）
  - 一欄時順序：班級、最近上課、題組
- 「新增班級」「新增題組」放在各自卡片的標題列右邊，次要按鈕、小尺寸（`.btn-small`）
- 「最近上課」的未批改提醒改成共用的小標籤樣式（見「上課紀錄」）

### 新增班級、新增題組、新增分組

- 表單放進一張 `.card`（像登入頁那樣），標題在卡片裡
- 新增分組頁的選項（隨機／自己分、組數…）照現有欄位，排進同一張卡片

### 班級頁

- 標題列：班級名 `h1`；右邊「加入碼 123456」＋「？」＋主要按鈕「開始上課」。窄螢幕時加入碼和按鈕換到標題下一行，不要擠在一起
- **學生名冊**：
  - 名冊表格最寬 800px（3 欄撐滿 1400px 太空）
  - 姓名連結照第 2 節「表格裡的連結」；修改／刪除改文字按鈕（刪除用危險色）
  - 「貼上名冊」改次要按鈕；「新增一位學生」那張卡片放在表格下面，維持現在的欄位
- **分組**：列表照第 2 節（分組名粗體、右邊「N 組」、列尾 ›）；「新增分組」次要按鈕
- **上課紀錄**：見下面「上課紀錄（班級頁的列表）」；「匯出多堂課」次要按鈕
- **班級設定**：現在的三張卡片保留；「刪除班級」那張的危險樣式不變。「班級名稱」的「儲存」維持主要按鈕（這個分頁只有它一個）

### 分組頁

- 標題列：`h1` 分組名，旁邊文字按鈕「✎ 改名」（開現在的「修改分組名稱」對話框）；右邊主要按鈕「投影顯示」
- 說明文字改成：「點學生可以換組。」（改名已經有按鈕了）
- **每一組的卡片**：
  - 標題列：組名（粗體）＋「N 人」，右邊文字按鈕「✎ 改名」（開現在的「修改組名」對話框，裡面照樣有「刪除這一組」）
  - 組名本身**不再是按鈕**，只是文字
  - 組員：一個一個的名牌，`--surface-soft` 底、1px `--border`、`--radius-sm`，至少 44px 高，整顆可點（換組）。一列放得下就並排
- 「＋ 新增一組」：次要按鈕，放在組卡片格子的最後面（像一張虛線框的空卡片也可以，整塊可點）
- 「未分組」卡片：維持虛線框，但用 1px
- 最下面一排：「重新隨機」「複製這套分組」改文字按鈕，「刪除這套分組」改危險文字按鈕。按鈕文字「刪除」改成「刪除這套分組」，免得以為是刪一組

### 題組頁

- 標題列：`h1` 題組名，旁邊文字按鈕「✎ 改名」；下一行「共 N 題，總分 N 分」；右邊次要按鈕「預覽全部」
- **題目列表**：一張卡片、每題一列（第 2 節的列表規則），不再一題一張卡片
  - 每列左邊：「第 N 題」粗體＋題型・分數（muted）；下一行題目開頭
  - 每列右邊：文字按鈕「複製」「上移」「下移」，危險文字按鈕「刪除」，最後是次要按鈕（小尺寸）「修改」
  - 寬度 < 900px 時，按鈕換到題目文字下面一行，靠左
  - 第一題的「上移」、最後一題的「下移」照樣停用（灰字）
- 「＋ 新增第 N 題」維持主要按鈕、維持在列表正下方
- 最下面：「複製整個題組」文字按鈕、「刪除題組」危險文字按鈕。「改題組名稱」已經移到標題旁的「✎ 改名」，這裡拿掉
- 「要新增哪一種題目？」對話框：五個題型按鈕現在全是主要按鈕（一整片藍）。改成次要按鈕的樣子（白底、1px 框、題型名粗體、說明 muted），滑鼠移上去 `--surface-soft`

### 題組預覽

- 每題的預覽放在白色卡片裡，題與題之間有間距；其他不變

### 題目編輯

- 選項框（`.option-edit`）改 1px；正確答案的選項維持 `--success-soft` 底＋`--success` 框
- 每個選項下面那排工具：
  - 「設為正確答案」／「✓ 正確答案」（單選）或「正確答案」勾選框（多選）**維持現樣**，放左邊
  - 「上移」「下移」改文字按鈕，「刪除」改危險文字按鈕，靠右
  - 手機寬度時整排不換成兩行以上（文字按鈕比較窄，應該放得下；放不下就讓右邊三個換到第二行）
- 頁面底部的「儲存」維持主要按鈕；其他按鈕維持次要或文字

### 上課紀錄（班級頁的列表）

- 表格現在已經整列可點（`row-link`），保留；改成日期不加底線、滑鼠移上去整列 `--surface-soft`、列尾 ›
- 「N 份簡答沒批改」改成共用的小標籤 `.badge`（放 `base.css`）：`--warning-soft` 底、`--warning` 字、`--radius-sm`、小字級、不要框線。順便做 `.badge-success`、`.badge-neutral`（`--surface-soft` 底、`--text-muted` 字）給之後用
- 「匯出多堂課」對話框裡的勾選清單：每一列整列可點（用 `<label>` 包住勾選框和文字）、1px 分隔線，勾選的列 `--primary-soft` 底

### 上課紀錄頁（單堂）

- 標題下的「出席 23 / 30」「平均分數 1 / 3」：做成兩張小的數字卡（白卡片，標籤 muted 小字在上、數字大字在下），並排；「下載 Excel」主要按鈕在右邊
- 學生成績表：姓名連結照第 2 節；「總分（滿分 3）⇅」排序按鈕維持，但不加底線，用 `--primary` 字
- 每題統計：每一題一列（第 2 節列表規則），整列可點進題目詳情
- 依分組看：每組一張卡片或一個區塊，維持現在的內容
- 頁面最下面的「刪除這堂紀錄」改危險文字按鈕（確認對話框不變）

### 題目詳情、簡答批改

- 題目文字框：白卡片
- 「上一題」「下一題」：次要按鈕，放在題號那一行的右邊，維持現在位置
- 長條圖：一般選項用 `--chart`、正確答案用 `--success`，底軌 `--surface-soft`、不要框線
- 「誰選了什麼」：每個選項一個區塊（白卡片、1px 框），正確答案那塊 `--success-soft` 底＋`--success` 框；學生名牌跟分組頁的名牌同樣式（但不能點，所以不要 hover 效果、高度可以小一點）
- 簡答批改：「只看沒批改的／全部」維持兩顆切換按鈕（選中的主要、沒選的次要）；學生答案框 `--surface-soft`；分數按鈕維持 72px，選中的主要按鈕樣式

### 學生歷次表現

- 標題下的出席統計做成跟上課紀錄頁一樣的數字卡
- 每堂課一列（第 2 節列表規則），整列可點進那堂課的紀錄

## 4. 窄螢幕

老師平常用 1366～1920 寬的電腦，但偶爾用手機看紀錄。每頁在 400px 寬：

- 不能有橫向捲軸（表格本身在 `.table-wrap` 裡橫向捲動可以）
- 標題列的按鈕換到下一行，不要把標題擠成直排
- 題組頁每題的按鈕換到題目文字下面

## 驗收

- `pnpm typecheck`、`pnpm test`、`pnpm build` 通過；PR 附 build 大小（老師端 JS 應該只多一點點）
- 不新增 npm 依賴；「✎」「›」「？」用文字字元
- **PR 附改前／改後截圖**（1366 寬，同一個畫面並排）：首頁（沒有上課中、有上課中各一張）、班級頁名冊、班級頁上課紀錄、分組頁、題組頁、「要新增哪一種題目？」對話框、題目編輯（單選題）、上課紀錄頁（學生成績，展開「？」說明）、題目詳情（單選）、簡答批改、學生歷次表現
- 400px 寬：首頁、題組頁、題目編輯頁
- 用鍵盤 Tab 走一遍首頁、題組頁、分組頁：整列連結、文字按鈕、「？」都看得到焦點外框；「？」按 Enter 能展開和收起
- 手動確認功能沒變：題目複製／上移／下移／刪除、分組換組／改組名／刪組／新增一組、名冊修改／刪除、多堂課勾選匯出，都照舊能用
