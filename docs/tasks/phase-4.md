# Phase 4：上課紀錄、統計、簡答批改、Excel 匯出

先讀 `CLAUDE.md`、`docs/PRODUCT.md`、`status.md`。Phase 3.5 已合併並部署，老師實際上過課，沒有新問題。

## 目標

下課後，老師可以回頭看每堂課的結果、批改簡答、看某位學生在這個班的歷次表現，並匯出 Excel。這個階段只做老師端，學生端不變。

## 名詞與計分規則（先定清楚，所有頁面和 Excel 都照這個算）

- **出席**：有加入這堂課（`lesson_students` 有資料）。沒加入的顯示「缺席」，不是 0 分
- **有出的題目**：狀態不是「未出題」的題目。從沒出過的題目在統計與 Excel 裡都不出現
- **沒作答**：有出席、題目有出，但沒有交答案，算 0 分
- **滿分**：這堂課所有「有出的題目」配分加總（包含簡答）
- **總分**：自動評分的得分＋已批改簡答的得分。還沒批改的簡答先算 0，畫面上顯示「還有 N 份簡答沒批改」提醒
- **正確率**：答對人數 ÷ 出席人數（沒作答算答錯）。簡答題不算正確率，改顯示平均分
- 時間一律以台灣時間（Asia/Taipei）顯示，格式像 `11/5（三）10:10`

這些規則寫成 `src/shared/` 裡的純函式並有測試；畫面和 Excel 都用同一套函式，不要各算各的。

## 簡答批改

- 資料：`answers` 表的簡答作答目前是 `status = 'pending'`、`score = NULL`。批改後寫入 `score`（0～配分的整數），`status` 改成 `graded`（新狀態，需要時加 migration 或只改程式，自行判斷）。`GradeResult` 的型別跟著擴充，學生端的下課結果遇到 `graded` 顯示「老師已批改（X 分）」
- 介面：在上課紀錄的簡答題頁面，一次顯示一位學生的作答（座號、姓名、內容，字要大好讀），下方是分數按鈕（0、1、2…到配分；配分超過 10 時改成數字輸入框）。按下分數就存，並自動跳到下一位還沒批改的學生
- 上方顯示「已批改 12／28」，可以切換「只看沒批改的／全部」，也可以點名單直接跳到某位學生改分
- 沒作答的學生不出現在批改名單裡

## 老師端畫面

### 班級頁新增「上課紀錄」分頁
- 列表：日期時間、題組名稱、出席人數（`26／30`）、平均得分率、簡答未批改數（有的話用醒目的小標籤）
- 由新到舊排序。點一列進入上課紀錄頁
- 進行中的課不顯示在這裡（顯示在首頁的「上課中」橫幅）

### 首頁
- 「最近上課」：最近 5 堂課（不分班級），點了進入上課紀錄頁

### 上課紀錄頁
- 標題：班級・題組・日期時間
- 摘要：出席 26／30、平均分數 7.2／10、簡答未批改數
- 主要按鈕：「下載 Excel」
- **學生成績表**（預設顯示）：座號、姓名、每一題（○／✕／—沒作答／分數），最後一欄總分。缺席整列淡色並寫「缺席」。表頭可以點「總分」排序；預設依座號
- **每題統計**：題號、題型、題目前 20 字、正確率（或簡答平均分）、作答人數。點一題進入題目詳情
- **題目詳情**：題目全文與正確答案、答案分布（沿用上課畫面的長條圖元件）、誰選了什麼（選擇／是非依選項分組列出座號姓名；填空列出每位學生每格的答案和對錯）。簡答題這裡就是批改畫面
- **依分組看**（班級有分組時才出現）：選一套分組，顯示每組的平均總分與出席人數。分組以「現在的分組」為準（不需要記錄上課當時的分組）
- 「刪除這堂紀錄」：放在頁面最下方，次要樣式，確認時寫出「學生在這堂課的作答和分數都會刪除，無法復原」

### 學生歷次表現
- 在學生名冊點學生姓名，進入該生頁面
- 表格：每堂課的日期、題組、出席／缺席、得分／滿分、得分率
- 最上方摘要：出席 12／14 堂、平均得分率
- 不需要畫圖表

## Excel 匯出

- 在**瀏覽器**產生 `.xlsx`，Worker 只提供 JSON
- 套件：可以加一個產生 xlsx 的小套件，或用 `fflate` 加手寫 SpreadsheetML。條件：**動態載入**（按下匯出才下載，不算進老師端首次載入的大小）、壓縮後 40 KB 以內、不用 SheetJS（npm 上的版本太舊，新版只在官方 CDN 發佈）。PR 說明寫選了什麼、多大
- 數字要存成數字（Excel 才能加總），不是文字；第一列表頭凍結；欄寬大致合適；檔名用中文，例如 `高二孝班_出師表_2026-11-05.xlsx`
- 工作表名稱最多 31 字，不能有 `[]:*?/\`，超過或有這些字元時自動處理

**單堂課的檔案**（上課紀錄頁「下載 Excel」）：
1. `成績`：座號、姓名、出席、第 1 題…第 N 題的得分、總分
2. `每題統計`：題號、題型、題目、配分、作答人數、正確率（或簡答平均分）
3. `作答明細`：座號、姓名、題號、作答內容（轉成人看得懂的文字，例如「B」「○」「說、悅」）、結果、得分

**整個班的檔案**（上課紀錄分頁「匯出多堂課」）：
- 先跳出清單勾選要匯出的課（預設全選），按「下載」
- `總表`：一列一位學生，一欄一堂課（表頭是日期＋題組名稱），格子是得分（缺席留空），最後兩欄是出席次數和平均得分率
- 每堂課再各一張工作表，內容同單堂的 `成績`

## 效能（重要）

免費方案每個請求的 CPU 時間很少（約 10ms），課越上越多，資料會一直累積：
- 列表、學生歷次表現、整班總表這類**跨多堂課的彙總，用 SQL 的 `SUM`／`COUNT`／`GROUP BY` 算**，不要把所有作答撈出來在 JS 裡解析 JSON
- 單堂課的詳細資料（含作答內容）一次一個請求；匯出多堂時，前端逐堂請求再組合，並顯示進度「準備中 3／12」
- 若需要可以加索引（例如 `answers` 依 `student_id` 已有索引，`lessons` 依 `class_id, ended_at`）
- 測試裡造一個「40 堂課 × 30 人 × 20 題」的資料，確認彙總 API 不是逐筆跑 JS 迴圈去解析作答（用查詢數量或程式結構檢查即可，不用真的測毫秒）

## 驗收

- `pnpm typecheck`、`pnpm test`、`pnpm build` 通過
- 測試至少涵蓋：計分規則的各種情況（缺席、沒作答、沒出的題目、未批改與已批改的簡答）、批改分數超出範圍被拒絕、批改不存在或非簡答的作答被拒絕、新 API 未登入回 401、刪除上課紀錄連帶刪除作答、工作表名稱處理、作答內容轉文字
- 下載一個單堂 Excel 和一個多堂 Excel，用程式重新讀回檢查內容（可以用暫存資料夾的工具，不要加進專案依賴），並說明是否能用 Excel 或 LibreOffice 正常開啟
- PR 附截圖：上課紀錄列表、上課紀錄頁（學生成績表）、題目詳情（單選）、簡答批改畫面、學生歷次表現
- PR 描述用老師的角度寫兩段流程：「下課後批改簡答並下載這堂的 Excel」「期末匯出整學期成績」
