# Phase 6：上課小工具（臨時出題、抽人、計時器）

先讀 `CLAUDE.md`、`docs/PRODUCT.md`、`status.md`。Phase 5 已合併並部署。

## 為什麼做

目前要用「舉手」一定得先備好題組，所以老師沒備課的那幾堂就不會打開它。這一輪加三個**不用備課也能用**的工具，讓老師每堂課都有理由開著：

1. **臨時出題**：上課中想到就問，老師口頭講或寫黑板，學生手機只出現 A／B／C／D 等按鈕
2. **隨機抽人**：抽一位同學（或一組）回答，只在老師畫面，學生不用動手機
3. **計時器**：投影上的大字倒數

另外「開始上課」改成**可以不選題組**。

## 1. 開始上課可以不選題組

- 「開始上課」第 2 步的第一個選項是「**不用題組**（只用臨時出題、抽人、計時器）」，預設不選，老師要點選
- 不用題組時，這堂課的題組名稱存成「隨堂」，上課紀錄、Excel 都照這個名字顯示
- 沒有任何題目的上課畫面：顯示加入碼面板，主要按鈕是「臨時出題」。不能因為沒有題目而出錯（目前 `questions[index]` 會是 `undefined`）

## 2. 上課畫面的工具按鈕

- 上課畫面加三個次要按鈕：「**臨時出題**」「**抽人**」「**計時器**」。整堂課都看得到（包括還沒出第 1 題時），用文字，不要收進選單
- 放在頂部列，和「加入碼」「名單」「全螢幕」「結束上課」同一排但分成兩群（工具在左、管理在右）。在 1366×768 不能換行或擠壓到看不清楚；放不下就自己調整，但要截圖說明
- 每個工具開一個 `Modal`，同時只開一個

## 3. 臨時出題

**老師操作（兩下就出題）**

- 按「臨時出題」→ Modal 裡選題型，三個大按鈕：「**選擇題**」「**是非題**」「**簡答題**」
- 選擇題下面有「選項數：－ 4 ＋」（2～6，預設 4）
- 「題目（可以不填）」一行輸入框，最多 200 字。說明文字：「不填的話，學生手機只會看到選項，請口頭說題目或寫在黑板上」
- 主要按鈕「**出題**」：建立後**立刻**推送給學生（跟「出這一題」一樣：正在作答的題目自動停止；正在互評時，用現有的「結束互評？」確認）
- 臨時題一律 1 分，不需要先設正確答案

**放在哪個位置**

- 臨時題插在**目前這一題的後面**，後面的題目往後挪；還沒出過任何題時放在最前面
- 這樣公布臨時題之後，「出下一題」會接著出題組原本的下一題

**停止作答之後（選擇題、是非題）**

- 結果長條圖照常顯示。上方一列「**正確答案是：** [A] [B] [C] [D]」（是非題是 [○ 對] [✕ 錯]），點一個就選定
- 次要按鈕「**這題不計分（只看大家怎麼選）**」
- 主要按鈕「公布答案」在選定答案或選了不計分之前**停用**，並提示「請先選正確答案，或選這題不計分」
- 公布時，伺服器用選定的答案**重新評分**這題所有作答（用 `gradeAnswer`），之後跟一般題目完全一樣
- 簡答題：跟現有簡答題一樣（可以互評、之後批改）

**學生端**

- 題目文字空白時，手機上顯示「請看投影或聽老師說明」（不要顯示「（題目文字）」）
- 選項文字空白時，只顯示大大的字母 A、B、C…（不要顯示「（選項內容）」）。選項整列可點、至少 48px 高
- 不計分的題目公布後，學生看到「這題不計分」和自己選了什麼，不顯示對錯
- 下課結果清單：不計分的題目顯示「不計分」

**老師投影畫面**：題目文字空白時顯示「（口頭提問）」，左側列表也顯示「（口頭提問）」，並在臨時題旁加個小標籤「臨時」。

## 4. 不計分的題目在紀錄裡怎麼算

- **不列入**任何總分、滿分、得分率、平均、學生成績表欄位、多堂 Excel
- 每題統計和題目詳情照樣顯示選項分布，標示「不計分」，不顯示正確率
- 出席判斷不變（交過任何答案就算出席，包括不計分的題目）
- 規則寫進 `src/shared/records.ts`，讓頁面和 Excel 一致；`src/worker/records.ts` 的 SQL 摘要也要跟著排除

## 5. 抽人

- Modal 上方切換「**抽一人**」／「**抽一組**」
- 抽一人：範圍「今天已加入的同學」或「全班」（有人加入時預設前者，否則預設全班）
- 抽一組：選一套分組（預設最新的），沒有分組時顯示「這個班還沒有分組」
- 主要按鈕「**抽！**」：大約 1 秒內快速輪換名字（用 `setInterval`，不要 CSS 動畫），停在結果。結果用投影大字：「12 號 王小明」或「第 3 組：成員名單」
- 「抽過的不再抽」預設打開；全部抽完時提示並提供「重新開始」。旁邊顯示「還有 N 人沒抽到」
- 抽過的名單存在 `sessionStorage`（key 帶上課 id），重新整理不會重來；讀寫要 try/catch
- 完全在老師端，不呼叫新 API、不通知學生、不存資料庫

## 6. 計時器

- Modal 裡選時間：「30 秒」「1 分鐘」「3 分鐘」「5 分鐘」，加一個「自訂（分鐘）」數字欄
- 按「開始」後 Modal 關閉，倒數**固定顯示在上課畫面右上角**，字要大（投影看得到），**不擋住題目和主要按鈕**
- 點倒數區可以「暫停／繼續」「關閉」
- 時間到：顯示「時間到」、變色，用 Web Audio 發一聲短嗶（不要音檔）。不要自動停止作答
- 只在老師端，不通知學生，重新整理後消失沒關係

## 資料

新 migration `0008`：`lesson_questions` 需要記住「是不是臨時題」「是不是不計分」，自行設計欄位。舊資料預設都是一般題、要計分。

## 安全要求（重點測試）

- 臨時出題、公布時設定答案的 API 都要老師登入，未登入回 401
- 公布前學生端拿不到正確答案（臨時題本來就沒有，但重新評分後也不能提早外流）
- 設定的答案要檢查：選擇題的索引在範圍內、是非題是 true／false；不合法回白話錯誤
- 只有臨時題可以在公布時設定答案；一般題傳答案進來要忽略或拒絕
- 臨時題的題型只能是 single、truefalse、essay；選項數 2～6

## 驗收

- `pnpm typecheck`、`pnpm test`、`pnpm build` 通過
- 測試至少涵蓋：不選題組開始上課；臨時題插入位置（還沒出題、出到中間、出到最後）與「出下一題」接回原題組；臨時出題會停止正在作答的題目；公布時重新評分正確；不計分題不影響 `analyze()` 的總分和滿分；上面「安全要求」每一條
- 手動測試：本機 1 個老師分頁 + 3 個學生視窗，用「不用題組」開一堂課，出一題沒有題目文字的選擇題、一題不計分的是非題；再用有題組的課，在第 2 題之後插一題臨時題
- PR 附截圖：1366×768 上課畫面（看得到工具按鈕）、臨時出題 Modal、停止後選正確答案的畫面、學生手機看到只有字母的選項、抽人結果、計時器在右上角
- PR 描述用老師和學生的角度各寫一段流程，附 `pnpm build` 的檔案大小
- 更新 `docs/PRODUCT.md`（典型的一堂課、新增「上課小工具」一節）和 `status.md`

- 抽人、計時器的結果推送到學生手機

- 題目圖片、Word 匯入
