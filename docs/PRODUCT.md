# 舉手 — 產品規格

## 誰在用、怎麼用

- **老師**：高中國文老師，對電腦不太熟。在教室用學校電腦（效能普通）接投影機，偶爾用自己的筆電或平板。
- **學生**：約 30 人，用自己的手機（各種舊機型），連學校 Wi-Fi 或行動網路。
- **情境**：上課當下使用。老師推一題、全班同時作答、老師看結果、揭曉答案、下一題。下課後老師回頭看統計。

## 典型的一堂課

1. 老師打開網站、登入，選班級，按「開始上課」，選一份題組；沒備題組也可以選「不用題組」
2. 投影畫面出現大大的**加入碼**（6 位數字），學生用手機打開網址或掃 QR code、點自己的座號
3. 老師看到「已加入 28／30 人」，按「出題」（沒有題組就按「臨時出題」）
4. 學生手機出現題目、作答、送出；老師畫面即時顯示「已作答 25 人」和答案分布
5. 老師按「停止作答」→「公布答案」，學生手機顯示自己對錯；簡答題可以先讓學生互評
6. 「出下一題」……途中想到就「臨時出題」，要點人回答就「抽人」或「搶答」，要限時討論就開「計時器」，最後「結束上課」
7. 下課後，老師在「上課紀錄」看每題正確率、每位學生表現、批改簡答，可以匯出 Excel

## 核心概念

| 名稱 | 說明 |
| --- | --- |
| 班級 | 例如「高二孝班」。有學生名冊（座號 + 姓名）和一個班級加入碼 |
| 學生 | 名冊裡的一個人。用「座號」識別 |
| 分組 | 一個班級可以有多套分組（例如「第一次報告分組」）。每套分組有數個組，每位學生最多在一組 |
| 題組 | 一組題目，可在不同班級重複使用 |
| 題目 | 五種題型，見下方 |
| 一堂課 | 一次上課紀錄：哪個班、用了哪些題、每個學生的作答 |

## 題型

| 題型 | 學生怎麼答 | 自動評分 |
| --- | --- | --- |
| 是非題 | 點「○」或「✕」 | 是 |
| 單選題 | 點一個選項 | 是 |
| 多選題 | 勾多個選項後送出 | 是，全對才給分 |
| 填空題 | 一題可有多個空格，每格輸入文字 | 是，見下方規則 |
| 簡答／申論 | 輸入一段文字 | 否，老師之後批改；上課時可以讓學生互評 |

填空題評分：每格可設定多個可接受答案。比對前先做 `NFKC` 正規化（全形半形統一）和去除前後空白；英文預設不分大小寫。全部格子都對才算對，但統計時要能看到每一格的正確率。

每題可以有題目文字、選填的說明、配分（預設 1 分）。圖片之後再做。

## 學生身分

- 學生**不需要帳號密碼**。輸入加入碼 → 從名冊點自己的座號和名字
- 第一次點選後，該座號綁定這支手機（瀏覽器存一個隨機 token）。其他手機再點同一座號會被擋下，顯示「這個座號已經有人使用，請找老師」
- 老師可以在上課畫面「解除綁定」某個座號（學生換手機、點錯人時）
- 重新整理頁面或斷線重連，要自動回到目前狀態，不用重新選座號

## 分組

- 建立方式：**隨機分組**（指定組數或每組人數，人數盡量平均）、**手動分組**（點學生 → 選組）
- 可以改組名、把某人移到別組、複製一套分組再修改
- 有「投影顯示」：大字列出每組成員
- 上課紀錄可以「依分組看」各組平均（用下課當時的分組）
- 學生自己選組：之後再考慮，先不做

## 統計（Phase 4）

- 每堂課：每題作答人數、正確率、選項分布；每位學生得分
- 跨堂課：某學生在這個班的歷次表現
- 匯出 Excel（一堂課一個檔，或選多堂）

## 同儕互評（Phase 5）

上課時針對簡答／申論題，讓學生匿名互相看答案、給分和評語。第一版只做「隨機、一人評一人、匿名」。

- 題目狀態多一個「互評中」：作答中 → 已停止 → **互評中** → 已公布。老師也可以按「跳過互評，直接公布」
- 老師按「開始互評」時，伺服器把**有交答案的學生**洗牌排成一圈，每人評下一位：每人剛好評 1 份、被評 1 份，不會評到自己。少於 2 人作答時不能開始。分配開始後就固定，之後有人加入或解除綁定也不重新分配
- 學生看到的只有對方的答案，**不顯示姓名和座號**；給 1～5 分，加一句評語（必填，1～200 字）。老師結束互評前可以修改。沒作答的學生不用評
- 老師的投影畫面顯示「互評中，已完成 N／M 人」。按「結束互評」或直接「出下一題」都會結束互評，還有人沒評完時會先確認
- 老師可以按「看評語」看到誰評了誰（會先提醒投影中學生會看到），不恰當的評語可以刪除；被刪的人會看到「這次沒有收到互評」
- 結束後，每位學生看到自己收到的分數和評語，**不顯示是誰評的**
- 互評**只給老師參考，不算進任何成績**。上課紀錄的批改畫面會用淡色小字顯示，每題統計顯示「互評平均」，單堂 Excel 多一張「互評」工作表
- 之後看效果再決定要不要做：自選互評對象、組內／跨組互評、一人評多份

## 上課小工具（Phase 6、8）

不用備課也能用的工具（臨時出題、抽人、搶答、計時器），在上課畫面頂部列（左邊一群），整堂課都按得到。

- **開始上課可以不選題組**：第 2 步選「不用題組」，這堂課的題組名稱是「隨堂」，紀錄和 Excel 都照這個名字
- **臨時出題**：選「選擇題（2～6 個選項）」「是非題」或「簡答題」，題目可以不填，按「出題」就推給學生
  - 不填題目時，學生手機顯示「請看投影或聽老師說明」，選擇題只有大大的 A、B、C…；投影和紀錄顯示「（口頭提問）」，列表標「臨時」
  - 插在目前這一題後面，所以公布後「出下一題」會接回題組原本的下一題；正在作答的題目會自動停止
  - 一律 1 分。停止作答後老師點「正確答案是：A／B／C…」（是非題 ○／✕），伺服器用這個答案重新評分；也可以選「這題不計分（只看大家怎麼選）」
  - **不計分的題目**不列入任何總分、滿分、得分率、平均、成績表欄位和多堂 Excel；每題統計和題目詳情照樣顯示選項分布並標示「不計分」；有作答照樣算出席。學生看到「這題不計分」和自己選了什麼
  - 臨時題不會存進題組，也沒有多選題、填空題、自訂配分
- **抽人**：抽一人（今天已加入的同學或全班）或抽一組（選一套分組），名字快速輪換約 1 秒後停在結果，用投影大字顯示。預設「抽過的不再抽」，抽完可以重新開始；重新整理不會重來。只在老師畫面，不通知學生、不存資料庫
- **搶答**（Phase 8）：老師口頭問一題，按「搶答」直接開始一輪。投影和學生手機一起倒數「3、2、1」，然後學生手機出現一顆很大的「搶！」
  - 投影依先後排出前 5 名（第 1 名最大），超過 5 人顯示「還有 N 人也按了」，下方寫「已加入 N 人，已經有 N 人按了」。學生只看到「你是第 N 個按的」，看不到別人
  - 倒數由伺服器決定（手機只收到「還有幾毫秒」，不靠手機時鐘），名次照伺服器收到的順序；重複按不會重複記錄
  - 「再搶一次」清掉排名重新倒數；「結束搶答」後手機回到原本的畫面
  - 搶答不會改變任何題目：作答中的繼續作答中、互評中的繼續互評中（老師想停止作答就自己按「停止作答」）。學生手機的搶答畫面蓋在題目上面，結束後回到原本的作答畫面，打到一半的內容還在、也可以送出
  - 搶答不進上課紀錄、成績、Excel，也不算出席；不保留歷史，結束上課就清掉。沒有任何聲音
- **計時器**：30 秒、1 分鐘、3 分鐘、5 分鐘或自訂分鐘數。大字倒數顯示在上課畫面右上角，可以暫停／繼續、關閉。時間到**不出聲**，畫面中央跳出大字「時間到」和「知道了」按鈕（蓋在所有東西上面，不會自己消失），按「知道了」或 Esc 關掉提示和計時器；不會自動停止作答。只在老師畫面，重新整理就消失

## 開發階段

| 階段 | 內容 |
| --- | --- |
| Phase 0 | 專案骨架、部署流程、老師登入 |
| Phase 1 | 班級、學生名冊、分組 |
| Phase 2 | 題組與題目編輯（五種題型） |
| Phase 3 | 上課：加入、推題、即時作答、揭曉 |
| Phase 4 | 上課紀錄、統計、Excel 匯出 |
| Phase 5 | 同儕互評 |
| Phase 6 | 上課小工具：臨時出題、抽人、計時器 |
| Phase 7 | Word 匯入（暫緩） |
| Phase 8 | 搶答；計時器時間到改成畫面提示 |
| 之後 | 題目圖片、學生自選組、其他想到的 |

## 明確不做

- 多位老師、多所學校、老師註冊
- 學生帳號密碼
- 離線模式、桌面程式、App
- 成績系統串接
